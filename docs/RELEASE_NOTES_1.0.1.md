Animated Screensaver 1.0.1 fixes startup and setup errors, with improvements for Steam Deck use without GabeCubeAura or a JSAUX Faceplate.

### Fixed

- A startup race that could display a Python exception immediately after installation or reload.
- Temporary errors remaining visible after the interface had recovered.
- Generic errors when a SteamGridDB key was missing, invalid or rejected, or when video tools were unavailable.
- Decoder work starting before detecting a missing ffprobe.
- An old Faceplate configuration interfering with a new screen-only installation after GCA or the device was removed.

Saved settings, prepared artwork, offline collection installation and Faceplate flash protections are preserved.

Download `Decky-Animated-Screensaver-v1.0.1.zip` and install it using Decky's **Install plugin from ZIP** option, or update through the plugin's Updates settings when available.
