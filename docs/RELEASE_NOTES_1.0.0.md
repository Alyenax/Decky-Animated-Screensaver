Animated Screensaver brings animated game artwork to Steam's screensaver through Decky.

- Build and reorder a collection, choose backgrounds, covers and logos, then preview, prepare and install it.
- Use animated artwork or original still images with gentle movement, including TV 16:9 and Steam Deck 16:10 framing.
- Add optional JSAUX Faceplate output through compatible GabeCubeAura, with synchronised or independent playback.
- See what Video tools downloads and where it is installed.
- Export settings and save complete diagnostics locally.
- Check public updates every 24 hours. Download and installation remain manual.

Download `Decky-Animated-Screensaver-v1.0.0.zip` and install it using Decky's **Install plugin from ZIP** option. See the [user guide](https://github.com/Alyenax/Decky-Animated-Screensaver/blob/main/docs/wiki/Home.md).

GPL-3.0-only. Created and maintained by Alyenax.

Software and package checks are complete. Native SteamOS installation, controller focus and physical JSAUX playback still need acceptance on the target devices.
