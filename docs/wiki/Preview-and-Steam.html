Preview and Steam playback

Preview a game

Open its artwork sheet and use the preview controls. DAS can preview a selected source before preparation. First use may download that source. Previewing does not prepare, install or activate the Steam screensaver.

Use the current-choices preview to inspect your edits. A prepared-version preview shows the existing converted media when available. These can differ while changes are waiting for preparation.

Preview the installed collection

After installation, preview the installed collection to check game order, artwork and branding. Pause and resume the preview with its controls. Close it before editing or starting another operation.

Actual DAS player rendered in a local browser. This is not a recording from SteamOS.

Start in Steam

Choose decky-animated-screensaver in Steam’s screensaver settings, then set the inactivity delay in Power settings. Leave Steam idle to test automatic activation.

The optional Faceplate request is tied to the installed Steam screensaver. An ordinary artwork preview does not send images over USB. See Faceplate integration.

If a preview works but Steam does not start the screensaver, check the selected screensaver and inactivity delay before rebuilding media.
