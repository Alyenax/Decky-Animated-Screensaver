# Preparation

Preparation downloads and converts the selected artwork. Installation makes the completed collection available to Steam. Saving artwork choices alone does neither.

![Confirm preparation, view progress, pause and resume](media/das-preparation.gif)

*Production interface with simulated progress and completion. The GIF explains controls; it does not represent conversion speed.*

## Prepare and install

1. Complete [Setup](Setup.md), add games and save any artwork choices.
2. Close running games.
3. Select **Prepare and install** or the collection’s update action.
4. Review the confirmation. When offered for an existing collection, **Missing / changed media** reuses valid prepared files. **Redo all** prepares the included backgrounds again while reusing valid downloaded sources.
5. Confirm, then follow the progress page.
6. After successful installation, [select the screensaver in Steam](Installation.md#select-the-installed-collection-in-steam).

The previous installed collection remains available until its replacement can be installed. A failed preparation does not mean that the working choices were installed.

## Pause, resume or cancel

Use **Pause** to suspend preparation and **Resume** to continue. **Cancel** stops the current operation. Review the resulting state before starting again. Files that are already valid can be reused by the next incremental preparation.

Do not judge preparation duration from this walkthrough: downloads, source formats, image sizes and collection size all affect it.

## TV and Faceplate status

When optional Faceplate output is enabled, DAS also prepares its images. TV readiness, Faceplate readiness and installation are shown separately where relevant. A prepared Faceplate file does not prove that it has been transferred to or displayed by the device.

Large Faceplate collections may use compact batches with independent playback. The TV collection remains available if the Faceplate is disconnected. See [Faceplate playback modes](GCA-Faceplate-Integration.md#choose-how-the-displays-play).

## After completion

Use the installed preview to check the collection. If preparation is incomplete, open the affected game, change its artwork or allow still images, then retry. See [Troubleshooting](Troubleshooting.md).
