# Privacy, credits and licence

## Online access

| Operation | Destination and data |
| --- | --- |
| Artwork browsing and download | SteamGridDB and artwork hosts. Your SteamGridDB key is used for its API requests. |
| Game search and discovery lists | Public Steam services for search, game names and player-count rankings; thumbnails may load from Steam artwork hosts. |
| Optional owned-game import | Steam over HTTPS, only when you select Import. |
| Optional video tools download | BtbN/FFmpeg-Builds on GitHub and GitHub release asset hosts, when you select Download. |
| Public update check | Public GitHub release metadata. No GitHub sign-in is required. |
| Prepared playback | Uses locally prepared files. |
| Settings export or support report | Saved locally; not uploaded by the public build. |

The SteamGridDB key is stored on the device. The optional Steam Web API key is used for the requested import, is not saved or exported, and is cleared after the attempt. See [Setup](Setup.md).
