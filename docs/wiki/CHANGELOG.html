Animated Screensaver changelog

Public release history.

1.0.1 - 2026-10-26

Fixes

  • Fix a startup race that could show a Python exception when opening the plugin immediately after installation or reload.
  • Clear temporary interface errors after a successful refresh and ignore outdated error responses.
  • Show clear setup messages for missing, invalid or rejected SteamGridDB keys and unavailable video tools. Keep the previous saved key when new input is invalid.
  • Detect a missing ffprobe before starting decoder work.
  • Keep screen-only installation independent of GCA and the JSAUX Faceplate, including after removing a previously configured device. Preserve saved preferences and prepared Faceplate files.
  • Preserve offline installation of already prepared collections without requiring a SteamGridDB key or video tools.

1.0.0 - 2026-10-25

Collections and artwork

  • Build a Steam screensaver collection from installed games, title search and discovery lists.
  • Select animated or still backgrounds, covers and logos for each game.
  • Reorder games from My collection or Add games.
  • Preview artwork before preparation and review the installed collection afterwards.
  • Prepare missing or changed media, or rebuild all included backgrounds. Pause, resume and cancel preparation.
  • Install the completed collection for selection in Steam. Reuse prepared files offline.

Playback

  • Configure time per game, shuffle, transitions, image framing and branding positions.
  • Support original artwork, TV 16:9 and Steam Deck 16:10 framing.
  • Render gentle still-image movement from the original image in the player; offer animated-media smoothing and reduced-motion settings.

Optional Faceplate integration

  • Prepare separate JSAUX artwork through a compatible GabeCubeAura installation.
  • Offer experimental synchronised playback or an independent loop, with automatic batches for larger collections.
  • Preview Faceplate files without a USB transfer. Use GCA for connection, hardware control and optional light-bar colour extension.

Setup and settings

  • Order Setup as SteamGridDB, video tools, then optional Steam library import.
  • Identify the video tools download: FFmpeg, ffprobe and Linux libraries (about 64 MB), its GitHub source and the exact installation folder.
  • Confirm a successful saved-key test with a green tick and message.
  • Export and import local JSON settings, with the saved location shown after export.
  • Check public releases anonymously every 24 hours, with immediate manual checking when idle. Downloading and installing each require a manual action.
  • Keep complete local diagnostic reports with Faceplate, player, Steam browser, preparation and delivery evidence. Display the saved path.
  • Remove private GitHub authentication, online settings/diagnostic uploads and automatic update download/installation.
