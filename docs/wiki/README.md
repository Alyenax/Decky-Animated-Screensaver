# Decky Animated Screensaver

This project is derived from [Steam Animated Screensaver](https://github.com/Alyenax/Steam-Animated-Screensaver).

Prepare a collection of game artwork and use it as Steam’s screensaver on Steam Deck or Steam Machine. Browse SteamGridDB, choose animated or still backgrounds, covers and logos, then prepare and install your collection from Decky.

## What it does

- Add installed games or search for other titles. Importing a Steam library is optional.
- Choose each game’s background, cover, logo and framing.
- Reorder your collection, set time per game and choose playback transitions.
- Preview choices, then prepare and install when ready. Prepared playback works offline.
- Know which video tools will be downloaded, their source and the exact installation folder before downloading.
- Check public updates every 24 hours; download and install manually.
- Export settings and save complete support reports locally.
- Optionally show separate artwork on a JSAUX Faceplate through [GabeCubeAura](GCA-Faceplate-Integration.md).

## Get started

1. Open **Animated Screensaver** in Decky, then **Settings → Setup**. Save and verify a SteamGridDB key, then install the video tools if needed.
2. Open **Add games** and select your games. Choose artwork from **My collection**.
3. Select **Prepare and install**, confirm, then wait for completion.
4. In Steam, select **decky-animated-screensaver** under **Settings → Customization → Screensaver**.

See the [wiki](Home.md) for installation, preparation, playback and settings. The [preparation walkthrough](Preparation.md) shows the steps in a GIF. Release changes are in the [changelog](CHANGELOG.md).

## Optional Faceplate

TV and Steam Deck playback work independently of GabeCubeAura. A connected JSAUX Pixel Matrix Faceplate requires a compatible GCA installation. DAS prepares the collection; GCA controls the hardware. [Set up the integration](GCA-Faceplate-Integration.md).
