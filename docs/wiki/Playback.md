# Playback settings

Open **Settings → Playback**.

| Control | Use |
| --- | --- |
| Time per game | Sets how long each game stays on screen. |
| Shuffle games | Plays games in a random order. Disabled during synchronised Faceplate playback. |
| Transition | Crossfade or fade through black between games. |
| Framing | Original, 16:9 TV or 16:10 Steam Deck. |
| Game name | Logo, title, both or hidden. |
| Show cover | Shows or hides the chosen cover. |
| Cover / logo position | Places the selected image in a screen corner. |
| Reduced motion | Reduces optional movement. |
| Steam inactivity settings | Opens Steam’s Power settings. |
| Interface language | English or French. |

After changing installed playback settings, update the collection and check its preview. A source preview may not show the player’s gentle movement or prepared animation smoothing.

Faceplate timing and transitions have their own controls. In synchronised mode, time per game follows the TV. In independent mode, the Faceplate uses its own time per game. See [integration settings](GCA-Faceplate-Integration.md).
