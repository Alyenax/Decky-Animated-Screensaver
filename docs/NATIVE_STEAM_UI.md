# Steam and Decky interface

Animated Screensaver uses native Decky controls, registered routes and controller
navigation. The quick panel opens My collection and Add games. A detected update
adds an explicit action leading to Updates. Settings contains Setup, Playback,
optional Faceplate controls, Storage and assistance, Advanced, and Updates.

On SteamOS, verify controller focus, Back navigation and previews in the actual
Decky interface. Desktop adapters do not establish native SteamOS acceptance.
