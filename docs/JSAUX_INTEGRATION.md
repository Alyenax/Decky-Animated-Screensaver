# Optional JSAUX integration

TV screensaver playback works independently. Optional JSAUX Faceplate output
requires a compatible GabeCubeAura installation and a detected device. DAS
prepares game artwork and an installed collection; GCA owns hardware access.

Choose synchronised or independent playback in Faceplate settings. Large
collections can use automatic compact batches. Preparation, transfer receipts
and optical playback are separate evidence; a ready preview does not establish
visible hardware playback.

Use the [Faceplate user guide](wiki/GCA-Faceplate-Integration.md) and retain the
pinned shared protocol in [JSAUX_CONTRACT_PIN.json](JSAUX_CONTRACT_PIN.json).
